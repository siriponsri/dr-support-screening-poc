# Future Experiments

These items are intentionally outside the current product boundary:

- broader modality support such as OCT, MRI, or PACS integration;
- PACS/DICOMweb transport and hospital identity integration;
- model calibration, clinical validation, and threshold studies;
- richer annotation collaboration beyond the current human/CVAT workflow;
- production-scale background scanning and multi-database storage;
- approved deployment automation for additional infrastructure providers.

None of these are required for the current review workstation or offline Model API acceptance.
