# KKU Clinical UI Theme

Customer-facing UI profile for DR Support Screening POC.

| Role | HEX | Use |
|---|---|---|
| KKU Primary / Red Soil | `#A73B24` | Primary CTA, active navigation, focus emphasis |
| Primary Dark / Deep Brick | `#7C291A` | Hover and selected emphasis |
| Primary Soft / Clay Tint | `#F4E5E0` | Selected row/background |
| Warm Accent / Muted Gold | `#C99A45` | Small secondary accent only |
| Ink | `#202428` | Main text |
| Secondary Text | `#667085` | Metadata/helper text |
| Surface | `#FCFBFA` | Application background |
| Panel | `#FFFFFF` | Cards and panels |
| Border | `#E5E7EB` | Dividers and borders |

Design rules: English-only; minimal, clean, professional and clinical; no gradient,
glassmorphism, sci-fi AI styling, dense decorative dashboards, or excessive shadows.
The KKU primary color is product chrome, not a lesion color and not an error color.

Lesion overlay colors remain deliberately independent and match the owner-created CVAT labels:

- MICROANEURYSM `#00D9FF`
- HEMORRHAGE `#8BFF3D`
- HARD_EXUDATE `#FF3CAC`
- SOFT_EXUDATE `#8B5CF6`

No KKU logo or institutional endorsement is included by this POC.
