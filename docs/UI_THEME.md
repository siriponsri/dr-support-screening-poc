# Clinical UI Theme

Customer-facing UI profile for DR Support Screening POC v2.

| Role | HEX | Use |
|---|---|---|
| Primary accent / Red Soil | `#A73B24` | Primary CTA, active navigation, focus emphasis |
| Primary hover / Deep Brick | `#8E311D` | Hover and selected emphasis |
| Soft accent / Clay Tint | `#F7ECE8` | Selected row/background, grade card |
| Warm accent / Muted Gold | `#C99A45` | Small secondary accent only |
| Text | `#1F2937` | Main text |
| Secondary text | `#6B7280` | Metadata/helper text |
| Background | `#FAFAF8` | Application background |
| Panel | `#FFFFFF` | Cards and panels |
| Border | `#E5E7EB` | Dividers and borders |

Design rules: English-only; minimal, clean, professional and clinical; no gradient,
glassmorphism, sci-fi AI styling, dense decorative dashboards, or excessive shadows.
The primary accent is product chrome, not a lesion color and not an error color.

Lesion overlay colors remain deliberately independent and match the owner-created CVAT labels:

- MICROANEURYSM `#00D9FF`
- HEMORRHAGE `#8BFF3D`
- HARD_EXUDATE `#FF3CAC`
- SOFT_EXUDATE `#8B5CF6`

No institutional logo or endorsement is included by this POC.
