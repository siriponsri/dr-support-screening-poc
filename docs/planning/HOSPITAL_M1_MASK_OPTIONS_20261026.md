## งานที่เดินต่อได้โดยไม่ต้องรอการตัดสินใจทางคลินิก

- E2E ทางเทคนิคใช้ข้อ 0/1 (ค่าปัจจุบัน) และบันทึกว่าไม่ใช่การยอมรับ mask ทางคลินิก
- เปิดข้อ 4 ใน review profile แบบ TEST_ONLY เพื่อพิสูจน์ส่วนเทคนิคของ AC-10
  (prepare, ซ่อน, คืน, save, reopen) ด้วยข้อมูล synthetic หรือ outputs เดิม โดยไม่ใช้ GPU
- gallery แบบ offline จาก outputs เดิม 230 เคส และแผนภาพขั้นตอน (MK-01, MK-04) ไม่ใช้ request

## สิ่งที่ owner ต้องตัดสิน

1. จะเปิดข้อ 4 (post-filter ที่คืนได้) สำหรับการทดสอบ TEST_ONLY ทางเทคนิคหรือไม่
2. จะลงทุนกับข้อ 2 (mask ที่ input) หรือไม่ ซึ่งต้องใช้ GPU request ใหม่และการเปรียบเทียบกับข้อ 0
3. นโยบาย profile (ข้อ 5)
4. การ adjudicate ทางคลินิก (MK-05): แพทย์ตรวจกล่องที่ถูกซ่อนและที่เหลือ พร้อมตัวหาร ก่อนอ้างว่าลดงานได้

ข้อแนะนำทางเทคนิค (ไม่ใช่การเลือกแทน): เริ่มที่ข้อ 4 แบบ TEST_ONLY เพราะย้อนกลับได้ ไม่เปลี่ยน input
และไม่ใช้ GPU แล้วค่อยตัดสินข้อ 2 หลังมีผล adjudication
