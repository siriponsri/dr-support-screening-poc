### Model API กลางบน dr-train (31 ต.ค. 2569)

- เปิด gateway แบบใช้ CPU ที่สั่ง GPU child เมื่อมีงาน พร้อมโควตารายวัน
- ภาพสาธารณะ HRF แบบ CFP 10 ภาพ ยืนยันชนิดและคุณภาพแล้วส่ง batch: RETFound ให้เกรดครบ **10 จาก 10** (10 calls คิดโควตาครั้งเดียวต่อภาพ ticket เสร็จ 10 ใบ)
- PRISM: **0 จาก 10** ระบบปฏิเสธก่อนเริ่มงานโมเดล เพราะภาพชุดนี้ไม่มีบันทึกการเตรียมภาพ (source projection) ที่อนุมัติ ต้องให้เจ้าของโครงการตัดสิน
- การตรวจของแพทย์: ภาพแรกยอมรับเกรด 2 ภาพที่สองแก้เป็นเกรด 3 ผล AI ดิบยังเป็นเกรด 2 ทั้งคู่ ส่งออกชุดข้อมูลแล้วตัวตรวจผ่าน (11 ภาพ ไม่มีภาพใดพร้อมใช้ train) เปิดระบบใหม่แล้วเกรด ผล AI และสถานะ batch ยังอยู่ครบ
- GPU: child เริ่ม 2 ครั้ง ใช้ 1,500 จาก 43,200 GPU-seconds หยุดเองหลังไม่มีงานประมาณ 300 วินาที ไม่เกินโควตา ไม่แตะ GPU1
- ภาพ UWF สาธารณะ (เจ้าของโครงการยืนยันสิทธิ์ใช้): USPEC บันทึกเกรดได้ 3 จาก 5 ภาพที่ส่ง อีก 2 ภาพถูกเกณฑ์สีของ Model API ปฏิเสธหลังส่ง (การเปลี่ยนเกณฑ์นี้เป็นการตัดสินใจของเจ้าของโครงการ)
- ระหว่างทดสอบพบและแก้: gateway หยุดชั่วคราวขณะเปิด child, ขั้นที่ถูกปฏิเสธค้าง batch, การปฏิเสธเชิงเงื่อนไขถูกนับเป็นการรอ, ช่อง PRISM ที่ไม่ได้ใช้ไม่ถูกคืน

### PRISM กับ mask A และ A2 บนภาพ UWF (31 ต.ค. 2569)

- รันซ้ำด้วยมือกับภาพ UWF 3 ภาพที่แพทย์อนุญาตจาก workspace ของโรงพยาบาล (ส่งครั้งเดียวต่อภาพ ไม่ส่งซ้ำ) เกรดและ annotation ของแพทย์ไม่เปลี่ยน
- การทดสอบจริงพบข้อบกพร่อง 2 ข้อและแก้แล้ว: การเตรียม PRISM ผ่าน gateway ส่งรหัสรอบผิด และ mask A ไม่ส่งค่า `boundary_confidence` ที่สัญญาข้อมูลของ PRISM ต้องการ
- mask A: กรอบบนขอบยางที่สว่างหายไปใน 2 ภาพ แต่ภาพหนึ่งยังมีกรอบบนแถบขอบยางที่มืด
- mask A2 (`uwf_rubber_rim_colour_a2_v1`, เจ้าของโครงการอนุมัติหลังดูภาพเทียบแบบส่วนตัว): ส่งจริง 2 calls กรอบบนแถบขอบมืดหายไป ไม่มีจอประสาทตาถูกตัดออก ผลของโมดูลตรงกับร่างที่อนุมัติทั้ง 34 ภาพทดสอบ (31 ภาพไม่ซ้ำ) และทุก mask ผ่านสัญญาข้อมูลของ PRISM
- ข้อจำกัด: A2 ตัดแบบระวัง บางภาพยังเหลือขอบมืดเล็กน้อย กรอบบนเปลือกตาและขนตายังมีอยู่ (อยู่นอกเป้าหมายระยะที่ 1)

## ทดสอบหน้าจอด้วย browser รอบนี้

ระหว่างถ่ายภาพหน้าจอสำหรับคู่มือผู้ใช้ (1 พ.ย. 2569) สคริปต์ `scripts/docs/capture_thai_manual.py` เปิดแอปจริงใน Microsoft Edge (Playwright) แบบเปิดการลงชื่อเข้าใช้ ใช้ภาษาไทย บัญชีทดสอบ 5 บทบาท ภาพสาธารณะ HRF 10 ภาพ และภาพสังเคราะห์ 1 ภาพกับ AI จำลอง (ข้อมูลตัวอย่างเท่านั้น) ทุกขั้นต่อไปนี้ทำงานผ่านในรอบสุดท้าย (27 ภาพ ไม่มีขั้นที่ล้มเหลว)

1. ลงชื่อเข้าใช้ และบังคับเปลี่ยนรหัสผ่านครั้งแรก (พยาบาล)
2. ผู้ดูแลระบบสร้าง Workspace จากโฟลเดอร์ภาพ และเปิดแท็บ Admin ทั้ง 4 แท็บ (ปุ่มทดสอบการเชื่อมต่อตอบว่าไม่ได้ตั้ง AI server)
3. แพทย์ยืนยันภาพ ดูผล AI จำลอง แก้เกรดจาก Moderate เป็น Severe ยืนยันกรอบที่ AI เสนอ วาดกรอบเอง แล้ว Finish
4. พยาบาลกรอกรายงานคัดกรองและบันทึกร่าง แพทย์ลงนาม เปิดหน้าพิมพ์ และรายการขึ้นในหน้า Referrals
5. จักษุแพทย์ให้เกรด Gold-100 แบบไม่เห็น AI แล้วเปิดดูผล AI
6. พยาบาลกด Confirm DR grade แล้วระบบปฏิเสธ ("A nurse's grade is preliminary. A physician confirms the DR grade.") ไม่มีการบันทึก

นี่เป็นการทดสอบหน้าจอด้วยข้อมูลตัวอย่างบนฐานข้อมูล SQLite ชั่วคราว ไม่ใช่การทดสอบกับ AI จริงหรือกับ PostgreSQL

## สิ่งที่ยังไม่ได้ทดสอบและข้อจำกัด

**ยังไม่ได้รัน**

- Server โรงพยาบาล (แบบ ข.) ยังไม่เคยรันบน server GPU ของโรงพยาบาลหรือบน RTX 3090 ยังไม่ได้วัดหน่วยความจำ GPU รวมของ 3 container ตัวติดตั้ง offline bundle และการกู้คืน ยังไม่เคยรันครบ
- การเชื่อมต่อผ่าน Cloudflare Tunnel และ Access จริง (แบบ ค.) ทดสอบเฉพาะแบบจำลอง header ในชุดทดสอบอัตโนมัติ
- การกู้คืนข้อมูลของ Docker web app และขั้นตอนอัปเดตบน Windows ยังไม่เคยซ้อม
- หลายผู้ใช้พร้อมกัน: มี sign-in ในเครื่องแล้ว แต่ Model API ยังใช้ token ร่วมตัวเดียว ยังไม่ได้ออก token รายบุคคลให้ใคร
- AI จริงยังไม่ได้รันซ้ำหลังย้าย gateway ไป `regular-20261031-r05`
- ทดสอบ PostgreSQL ในรอบนี้ถูกข้าม (ไม่ได้ตั้งฐานข้อมูลทดสอบ)
- ไม่มีการประเมินความแม่นยำทางคลินิกของ AI หรือของระบบ

**ข้อจำกัดที่รู้แล้ว**

- PRISM บนภาพสาธารณะชุดเดิมถูกปฏิเสธก่อนเริ่มงานโมเดล (ไม่มีบันทึก source projection ที่อนุมัติ)
- เกณฑ์สีของ Model API ปฏิเสธภาพ UWF สาธารณะบางภาพ
- แอปยังเปิดให้ส่ง PRISM แบบ batch กับภาพที่คุณภาพยังเป็น NOT_EVALUATED แต่ host รับเฉพาะ GRADABLE (defect ที่รู้แล้ว รอแก้)
- mask A2 ตัดแบบระวัง บางภาพยังเหลือขอบมืด กรอบบนเปลือกตาและขนตายังมีอยู่
- การเปิดแอป demo ทำให้ GPU child เริ่มทำงาน (คิดหนึ่งช่วงต่อการเปิดหนึ่งครั้ง) และงานที่รอคิวถือ lock ของแอปได้นานสุด 300 วินาที
- ทดสอบ frontend บางตัวช้าและล้มเหลวแบบสุ่มเมื่อรันเต็มชุดพร้อมกัน แต่ผ่านเมื่อรันเดี่ยว บันทึกไว้ ไม่ได้ผ่อนเกณฑ์
- ข้อความแจ้งเรื่องสิทธิ์จาก server ยังเป็นภาษาอังกฤษ และถ้อยคำไทยในคู่มือให้เกรด (เกณฑ์ ICO) และคำตอบ Yes/No ในแบบรายงานยังรอแพทย์ตรวจ
- installation candidate `0.8.0-m1-regular.rc1` build และทดสอบการแตกไฟล์แล้ว ยังไม่ใช่รุ่นสุดท้าย
