People and boundariesThree operating roles

Each role has a clear responsibility.

01Clinician / reviewer

Confirms image context, records the final DR grade, and confirms the active annotation set when required.

02Dataset operator

Selects the Workspace, checks task-specific readiness, and exports the provenance-preserving package.

03Hospital operator

Starts the review workstation and the separate Model API. Does not replace clinician review.

Maintainers verify model provenance, application behavior, and release documentation. CVAT Online is optional for dense geometry work.

Lesion readiness milestone

An ROI correction or removal is an optional edit. It is not a fourth confirmation queue.

Dataset readinessSeparate task outputs

DR-ready and Lesion-ready are independent states.

DR-readyGrade confirmed

Requires valid source provenance, an included fundus image, acceptable image state, and a final clinician grade with reviewer and timestamp.

Lesion-readySet confirmed

Requires valid source provenance, an included fundus image, and a current annotation confirmation whose hash matches the active set.

AI-only evidenceNot ground truth

Displayed AI output does not silently promote itself into a training-ready annotation.

Models & AuditRead-only inspection

Technical provenance is visible without becoming another clinician queue.

Model identity

RETFound and PRISM-DR model IDs, revisions, runtime state, and limitations.

Case provenance

Inference metadata, source SHA, analysis SHA, detection counts, and annotation provenance.

Human relationship

Original AI evidence remains separate from human correction, addition, removal, or CVAT import.
