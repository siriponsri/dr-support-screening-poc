# Team presentation

Double-click `PRESENT.cmd` in the project root (or open `presentation/index.html`) to show the deck in the
default browser; it works offline. Keys: Right, Space or PageDown for the next step, Left or PageUp to go
back, Home and End for the first and last slide, F for fullscreen, O for the slide overview (click a slide
to jump), H for the key list; a click on the left third of the screen goes back, elsewhere goes forward, and
the address ends in `#/N` for slide N. To edit, change the text inside each `<section class="slide">` in
`index.html`; elements with `class="frag" data-f="N"` appear on the Nth key press, colours and sizes follow
`DESIGN.md` and live in `deck.css`, and `deck.js` is the small slide engine (no external libraries; the
Inter font is embedded in `vendor/inter.css` under the SIL Open Font License). Use only public or
illustrated images, never patient data.
